# Threads

Мастер-промт делает контент-план для Threads на день.

## Для кого создан этот мастер-промт?

Для экспертов, блогеров и предпринимателей, которые ведут Threads, чтобы растить аудиторию и переливать её в Telegram или на другую площадку.

## Как это работает?

Из исследования аудитории собирает девять 9 веток с рубрикой, форматом, хуком и текстом каждой так, чтобы аккаунт рос, а часть постов вела людей на твою посадочную страницу.

## Для кого создан этот мастер-промт?

### Глубинное исследование клиента мечты

Промт читает файлы из [исследования клиента мечты](https://github.com/BermanRoman/prompt-audience-research) и на этой основе фиксирует голос: как автор говорит с этой аудиторией, какими словами и на какой дистанции.

Этот голос держится во всех девяти постах, чтобы за планом чувствовался один живой автор, а не девять разных.

### Баланс охвата и конверсии

Не все посты делают одно и то же:

- Охватные разгоняют аккаунт и приводят новых людей без призывов.
- Конверсионные едут на этой волне и ведут читателя к следующему шагу с явным CTA.
- Смешанные дают пользу и мягко указывают направление.

Промт ставит их в пропорции 4 охватных, 3 конверсионных и 2 смешанных и чередует так, чтобы охват подпитывал конверсию, а не существовал сам по себе.

### Рубрики под разные задачи

Контент идёт по пяти рубрикам:

- Мои грабли.
- Подборки и списки.
- Наблюдение из жизни.
- Провокационный вопрос.
- Личная история с уязвимостью.

Одни строят доверие, другие разжигают реакцию и охват.

Каждая встречается в плане хотя бы раз, чтобы темы не сужались к одному типу.

### Hook

Для каждой ветки промт пишет первое предложение, которое останавливает холодного человека без контекста.

Он выбирает одну из шести механик хуков под рубрику и доминирующую боль и пишет его языком аудитории, а не языком эксперта.

### Нейропаттерн-чек

Перед показом промт прогоняет все девять постов через нейропаттерн-чек в два прохода:

1. Ищет ИИ-маркеры: канцелярит, штампы, симметричные конструкции и дежурные обороты.
2. Переписывает найденное целиком, а не вычёркивает по слову.

Так план не пахнет нейросетью.

В итоге ты получаешь готовый контент-план на день: девять веток под публикацию со сводкой по балансу охватных, конверсионных и смешанных постов.

## Как пользоваться?

1. Создай новый проект в Claude.
2. Открой файл threads-content.md, скопируй его содержимое кнопкой «Copy» и вставь в поле «Инструкции» проекта.
3. Напиши в чате проекта сообщение: _«Начинаем работу по созданию контента для Threads, согласно заложенной в тебя инструкции»_
