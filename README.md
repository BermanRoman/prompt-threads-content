# Threads

Мастер-промт делает контент-план для Threads на день.

## Для кого создан этот мастер-промт?

Для экспертов, блогеров и предпринимателей, которые ведут Threads, чтобы растить аудиторию и переливать её на посадочную страницу — клип-лендинг по ссылке в шапке профиля.

## Как это работает?

Из исследования аудитории промт собирает контент-план на день: 3–4 поста, по одному на каждую плоскость взаимодействия, так, чтобы аккаунт рос за счёт охвата, а часть постов вела людей в воронку.

В основе — простой принцип: алгоритм нельзя обыграть, он зеркало и разносит то, на что уже среагировали живые люди.

Поэтому промт пишет не «под алгоритм», а под живого человека так, чтобы тот остановился, что-то почувствовал и что-то сделал — прокомментировал, сохранил, репостнул, зашёл в профиль.

### Глубинное исследование клиента мечты

Промт читает файлы из [исследования клиента мечты](https://github.com/BermanRoman/prompt-audience-research) и фиксирует голос: автор говорит как наблюдатель и брокер, на «ты», без выдуманной биографии.

Этот голос держится во всех постах, чтобы за планом чувствовался один живой человек.

### Четыре плоскости взаимодействия

Посты не равны по задаче, и плоскости не равны по силе:

- Юзер — юзер: двигатель охвата. Голое приглашение высказаться, на пиковом слоте.
- Юзер — игра: прогрев. История и узнавание.
- Создатель — игра: авторитет. Брокерская насмотренность.
- Создатель — юзер: доверие и конверсия. Прямое обращение, ответы в комментах и заслуженная дверь в шапку.

Пока у аккаунта нет охвата, юзер-юзер главный, остальные — поддержка.

### Story-craft: хук плюс история

Прогревные посты строятся как история с хуком сверху по методологии клип-лендинга (Magic Model и Invisible Funnel): двухчастный хук цепляет, а история голосом знакомого ведёт читателя по психоэмоциональным состояниям от боли к вере.

Конверсия — это story-ветка, мини клип-лендинг, который греет и продаёт клик в шапку.

### Докрутка историй на достоверность

Каждая история прогоняется по восьми пунктам, чтобы не звучать как пиздёж: конкретная победа, скромная цифра, трение, рассказчик-свидетель, ноль слоганов, показанный момент, живая деталь и инсайдерский язык из мира клиента.

Корень — детали из реального кейса, а не из головы.

### Рубрики и механики хуков

Контент идёт по пяти рубрикам (Мои грабли, Подборки и списки, Наблюдение из жизни, Провокационный вопрос, Личная история с уязвимостью) и шести механикам хуков, выбранным под рубрику и доминирующую боль аудитории.

### Живой русский, без перевода с американского

Промт пишет так, как говорят русские мужики между собой — прямо, сухо, с иронией, через конкретику.

Он вырезает интонацию англоязычного маркетинга: приделанную к просьбе выгоду, рассказывание читателю его же чувств, давящую грусть и оптимизированную структуру «вопрос — меню — CTA».

### Нейропаттерн-чек

Перед показом все посты прогоняются через нейропаттерн-чек в три прохода:

1. Категории AI-маркеров — каждое предложение с маркером переписывается целиком.
2. Финальный антиИИ-вопрос — ритм, конкретика, голос и проверка на перевод с американского.
3. Структурное разнообразие на уровне всего дня — ни одна пара постов не делит структурную форму.

Так план не пахнет нейросетью.

В итоге ты получаешь готовый контент-план на день: 3–4 поста под публикацию, готовые к копипасту, плюс конверсионную story-ветку, когда дверь в шапку заслужена.

## Как пользоваться?

1. Создай новый проект в Claude.
2. Открой файл **[threads-content.md](https://github.com/BermanRoman/prompt-threads-content/blob/main/threads-content.md)**, скопируй его содержимое кнопкой «Copy» и вставь в поле «Инструкции» проекта.
3. Загрузи файл **[methodology.md](https://github.com/BermanRoman/prompt-threads-content/blob/main/methodology.md)** в знания проекта — без методички промт не стартует.
4. Подготовь исследование ЦА (инструмент [prompt-audience-research](https://github.com/BermanRoman/prompt-audience-research)) и ссылку на клип-лендинг в шапке профиля.
5. Напиши в чате проекта сообщение: _«Начинаем работу по созданию контента для Threads, согласно заложенной в тебя инструкции»_
